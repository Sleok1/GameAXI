# GameAXI

Мини-мир в стиле «Трон: Наследие»: NPC живут, развиваются и строят узлы, а игрок может наблюдать и перемещаться.

## Что внутри

- Генерируемый мир из плиток.
- NPC с базовыми потребностями: отдых, сбор ресурсов, строительство.
- Эволюция мира: ресурсы восстанавливаются, появляются новые узлы.
- Цикл дня/ночи и HUD с показателями мира.

## Управление

- WASD / стрелки — движение игрока.
- Esc — выход.

## Требования

- Python 3.10+

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python src/main.py
```

# GameAXI 3D Micro World

Мини‑мир в стиле «Трон: Наследие», сделанный на **three.js** — движке, который позволяет делать качественные 3D‑игры прямо в браузере.

## Что внутри

- Полноценная 3D‑сцена с освещением и туманом.
- NPC с простой «жизненной» логикой: отдых, сбор ресурсов, строительство узлов.
- Ресурсы восстанавливаются, узлы создаются динамически.
- Управление от первого лица.

## Запуск

Просто откройте `index.html` в браузере (Chrome/Edge).

> Если браузер блокирует загрузку модулей, запустите локальный сервер:

```bash
python -m http.server 8000
```

И откройте `http://localhost:8000`.

## Управление

- WASD — движение.
- ЛКМ — захват мыши (осмотр).
- Esc — выход из захвата.
